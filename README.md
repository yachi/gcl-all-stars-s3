# GCL All-Stars Season 3 report

Standings, results, head-to-head and VOD round stats for GCL All-Stars Season 3 (TE:C Zone Battle and TETR.IO, Americas and Europe/Asia).

Live site: https://yachi.github.io/gcl-all-stars-s3/

## Updating

`index.html` is the whole report (self-contained). To republish, replace `index.html` (and `vod-rounds.json` if the round data changed) and push to `main`; the Pages workflow redeploys automatically.
